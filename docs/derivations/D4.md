## 1. Assumptions and Definitions

Consider a segment tree built over an array of \(n\) elements, indexed from \(0\) to \(n-1\).

Each node \(v\) represents a contiguous interval \([t_l,t_r]\). If \(t_l=t_r\), the node is a leaf. Otherwise, the interval is divided into two children using:

\[
t_m=t_l+\left\lfloor\frac{t_r-t_l}{2}\right\rfloor
\]

The left child represents \([t_l,t_m]\), and the right child represents \([t_m+1,t_r]\).

A range operation is performed on a contiguous interval \([l,r]\), where:

\[
0\leq l\leq r<n
\]

For any node interval \(I_v=[t_l,t_r]\), we distinguish three cases:

1. **Fully covered:** \(I_v\subseteq[l,r]\).
2. **Partially intersected:** \(I_v\cap[l,r]\neq\varnothing\), but \(I_v\not\subseteq[l,r]\).
3. **Disjoint:** \(I_v\cap[l,r]=\varnothing\).

The recursive implementation visits only fully covered and partially intersected nodes. Disjoint children are skipped.

The analysis below counts tree-node entries during a single range operation. The same argument applies to both range updates and range queries.

## 2. Height of the Segment Tree

At every internal node, the represented interval is divided approximately in half.

Let \(H\) denote the maximum depth of the tree, with the root at depth \(0\). Since the intervals are repeatedly divided until each leaf contains one element:

\[
H\leq\lceil\log_2 n\rceil
\]

Consequently, the number of levels, including the root level, is bounded by:

\[
H+1\leq\lceil\log_2 n\rceil+1
\]

Thus, the height of the segment tree is:

\[
H=O(\log n)
\]

## 3. Bound on Partially Intersected Nodes

Consider any fixed depth \(d\) of the segment tree.

The node intervals at this depth are disjoint and appear in the same order as the original array elements.

A partially intersected node must contain at least one of the two boundaries of the requested range:

- The left boundary \(l\).
- The right boundary \(r\).

This is because an interval that intersects \([l,r]\), but is not fully contained in it, must extend beyond at least one of these boundaries.

Since the node intervals at a fixed depth are disjoint, at most one node can contain \(l\), and at most one node can contain \(r\).

Therefore, the number of partially intersected nodes at any depth is bounded by:

\[
\boxed{P_d\leq 2}
\]

where \(P_d\) denotes the number of partially intersected nodes at depth \(d\).

This bound holds independently of the size of the array.

## 4. Bound on Fully Covered Nodes

A fully covered node is reached during recursion only when its parent is partially intersected. The exception is the root, which may itself be fully covered.

Consider a partially intersected internal node.

Its two children partition the parent's interval. Both children cannot be fully covered, because that would mean their union, and hence the entire parent interval, is fully covered. This contradicts the assumption that the parent is partially intersected.

Therefore, each partially intersected parent can have at most one fully covered child.

From Section 3, there are at most two partially intersected parents at any depth. Hence, at the next depth, the number of newly visited fully covered children is at most:

\[
\boxed{F_d\leq 2}
\]

where \(F_d\) denotes the number of fully covered nodes reached from partially intersected parents at the preceding depth.

These fully covered nodes are the canonical segment-tree intervals that represent portions of the requested range. Once such a node is reached, recursion terminates at that node; its descendants are not visited.

If the root is fully covered, it is the only visited node, and no descendants are entered. This case also satisfies the overall complexity bound.

## 5. Total Number of Visited Nodes

At any depth \(d\), every visited node is either partially intersected or fully covered.

Using the bounds established above:

\[
P_d\leq 2,\qquad F_d\leq 2
\]

Therefore, for every level below the root:

\[
V_d=P_d+F_d\leq 4
\]

The root contributes at most one additional node, which is also within the same constant bound.

Since the tree contains at most \(H+1\) levels, the total number of visited nodes is bounded by:

\[
V\leq 4(H+1)
\]

Using the height bound:

\[
V\leq 4(\lceil\log_2 n\rceil+1)
\]

Thus:

\[
\boxed{V=O(\log n)}
\]

This proves that the recursive decomposition of a contiguous range visits only logarithmically many segment-tree nodes.

## 6. Application to Range Updates and Queries

### 6.1 Range Update

The `update_tree()` function performs the following operations:

1. Increments the node-visit counter.
2. Checks whether the current node is fully covered by the requested range.
3. If fully covered, applies the affine transformation to the node and terminates recursion at that node.
4. Otherwise, propagates any pending lazy transformation using `push()`.
5. Recursively visits only the children that intersect the requested range.
6. Recomputes the current node's aggregate using `pull()`.

A fully covered node is processed without visiting its descendants. The affine transformation updates the stored aggregate and the pending lazy tag in constant time.

A partially intersected node performs a constant amount of additional work, apart from its recursive calls.

Since the number of visited nodes is \(O(\log n)\), and each node requires \(O(1)\) local work:

\[
\boxed{T_{\text{update}}(n)=O(\log n)}
\]

### 6.2 Range Query

The `query_tree()` function follows the same interval decomposition:

1. Increments the node-visit counter.
2. Checks whether the current node is fully covered.
3. If fully covered, returns its stored aggregate without visiting descendants.
4. Otherwise, propagates any pending lazy transformation using `push()`.
5. Recursively queries the intersecting child or children.
6. Merges the returned aggregates when both children contribute.

A fully covered node returns its stored sum and, in exact-extrema mode, its minimum and maximum.

Each visited node performs a constant amount of local work, excluding its recursive calls.

Therefore:

\[
\boxed{T_{\text{query}}(n)=O(\log n)}
\]

## 7. Effect of Lazy Propagation

Lazy propagation preserves the logarithmic complexity established above.

When `push()` is called, the pending affine transformation is applied to the two children, and the parent's pending tag is reset to the identity transformation.

This operation requires constant work because it updates only the immediate children. It does not recursively traverse their descendants.

Similarly, `apply()` updates a node's stored aggregate and composes its lazy tag in constant time.

Consequently, lazy propagation does not introduce an additional traversal of the segment tree. Its work is bounded by a constant amount per visited node.

The asymptotic complexities therefore remain:

\[
\boxed{
T_{\text{update}}(n)=T_{\text{query}}(n)=O(\log n)
}
\]

## 8. Connection to the Implementation

The derivation corresponds to the implementation in `src/structA/module.cpp`.

| Function | Role in the implementation |
|---|---|
| `update_tree()` | Performs recursive range updates, stopping at fully covered nodes and skipping disjoint children. |
| `query_tree()` | Performs recursive range queries and combines the results from intersecting children. |
| `push()` | Propagates pending affine transformations to the immediate children. |
| `apply()` | Updates a node's aggregate and composes its lazy tag. |
| `pull()` | Recomputes a parent aggregate from its children. |

The implementation also maintains `stats.nodes_visited`. This counter is incremented whenever `update_tree()` or `query_tree()` enters a node.

According to the shared interface contract, the counter excludes tree construction, invariant checking, and propagation calls that do not recursively enter another node.

Therefore, `stats.nodes_visited` measures the structural node entries analyzed in this derivation. It can be used to verify experimentally that the number of node visits grows logarithmically with the size of the array for contiguous range operations.

## 9. Conclusion

For a contiguous range operation, the segment-tree recursion visits only nodes that intersect the requested interval.

At every depth, there are at most two partially intersected nodes. Each such node can contribute at most one fully covered child, giving at most two newly visited fully covered nodes at the next depth. Fully covered nodes terminate recursion, while disjoint children are skipped.

Since the height of the segment tree is \(O(\log n)\), the total number of visited nodes is also \(O(\log n)\).

As each visited node requires constant local work, both range updates and range queries have logarithmic time complexity:

\[
\boxed{
T_{\text{update}}(n)=T_{\text{query}}(n)=O(\log n)
}
\]

Lazy propagation allows fully covered segments to be updated without visiting their individual elements, preserving this complexity.
