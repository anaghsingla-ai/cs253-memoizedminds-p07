## Abstract
This document provides the formal mathematical proof of the correctness of the lazy segment tree implementation in Structure A. Specifically, we prove the fundamental invariant that **node aggregates always include the effects of their own pending lazy tags**. We establish that this invariant is strictly preserved across all segment tree operations: complete interval updates (`apply`), lazy propagation (`push`), partial interval updates, and child aggregate merges (`pull`). We also establish correctness for both operating modes: modular range sums under arbitrary gains and offsets ($\pmod{998244353}$), and exact range extrema (minimum and maximum) under restricted gains $a \in \{-1, 0, 1\}$.

## 1. System Model & Mathematical Preliminaries

### 1.1. Underlying Data & Query Domain
Let $A = [x_0, x_1, \dots, x_{n-1}]$ be an array of $n$ elements. We consider two operational regimes:
1. **Modular Sum Regime ($\text{Mode} = \mathtt{modular\_sum}$):**  
   Elements belong to the finite ring $\mathbb{Z}_M$ where $M = 998244353$ (a prime). Values and offsets belong to $\mathbb{Z}_M$.
2. **Exact Extrema Regime ($\text{Mode} = \mathtt{exact\_extrema}$):**  
   Elements belong to the integer domain $\mathbb{Z}$ (represented as signed 64-bit integers `int64_t`).

### 1.2. Affine Transformation Family
An affine update operation is parameterized by a tag $\tau = (a, b)$, representing the mapping:
$$f_{\tau}(x) = a \cdot x + b$$

* In $\mathtt{modular\_sum}$, $a, b \in \mathbb{Z}_M$, and arithmetic is conducted modulo $M$.
* In $\mathtt{exact\_extrema}$, $b \in \mathbb{Z}$ and the multiplicative gain is constrained to $a \in \{-1, 0, 1\}$.

#### Proposition 1.1 (Monoid of Affine Transformations under Composition)
Let $\tau_1 = (a_1, b_1)$ and $\tau_2 = (a_2, b_2)$ be two affine tags. The composition $f_{\tau_2} \circ f_{\tau_1}$ (applying $\tau_1$ first, followed by $\tau_2$) is itself an affine transformation:
$$(f_{\tau_2} \circ f_{\tau_1})(x) = f_{\tau_2}(a_1 x + b_1) = a_2(a_1 x + b_1) + b_2 = (a_2 a_1)x + (a_2 b_1 + b_2)$$

Hence, the composition operator $\odot$ defined by:
$$\tau_2 \odot \tau_1 = (a_2 a_1, a_2 b_1 + b_2)$$
forms a monoid over the parameter space with identity element $\tau_{\text{id}} = (1, 0)$:
* **Identity:** $\tau \odot (1, 0) = (1, 0) \odot \tau = \tau$.
* **Associativity:** For any $\tau_1, \tau_2, \tau_3$, $(\tau_3 \odot \tau_2) \odot \tau_1 = \tau_3 \odot (\tau_2 \odot \tau_1)$.

*Proof of Associativity:*
$$\begin{aligned}
(\tau_3 \odot \tau_2) \odot \tau_1 &= (a_3 a_2, a_3 b_2 + b_3) \odot (a_1, b_1) \\
&= ((a_3 a_2) a_1, (a_3 a_2) b_1 + (a_3 b_2 + b_3)) \\
&= (a_3 a_2 a_1, a_3 a_2 b_1 + a_3 b_2 + b_3)
\end{aligned}$$
Similarly,
$$\begin{aligned}
\tau_3 \odot (\tau_2 \odot \tau_1) &= (a_3, b_3) \odot (a_2 a_1, a_2 b_1 + b_2) \\
&= (a_3 (a_2 a_1), a_3 (a_2 b_1 + b_2) + b_3) \\
&= (a_3 a_2 a_1, a_3 a_2 b_1 + a_3 b_2 + b_3)
\end{aligned}$$
Equality holds identically. $\blacksquare$

## 2. Tree Structure and the Core Invariant

### 2.1. Node State Representation
Each node $u$ in the segment tree $\mathcal{T}$ represents a contiguous interval $[tl_u, tr_u]$ of length $|u| = tr_u - tl_u + 1$.  
A node $u$ stores a 5-tuple:
$$u = \langle \Sigma_u, m_u, M_u, \tau_u \rangle$$
where:
* $\Sigma_u \in \mathbb{Z}_M$: Cached range sum modulo $M$.
* $m_u, M_u \in \mathbb{Z} \cup \{\bot\}$: Cached minimum and maximum values (defined in $\mathtt{exact\_extrema}$, $\bot$ otherwise).
* $\tau_u = (a_u, b_u)$: Pending lazy affine tag waiting to be propagated to proper descendants of $u$.

### 2.2. The Fundamental Invariant $\mathcal{I}(u)$
For every node $u \in \mathcal{T}$:

> **Core Invariant $\mathcal{I}(u)$:**  
> The aggregates stored in node $u$ ($\Sigma_u, m_u, M_u$) **already reflect the complete sequence of updates applied to interval $[tl_u, tr_u]$**, including its own pending tag $\tau_u$.  
> The tag $\tau_u$ represents transformations applied to $u$ that have **not yet been transmitted to the children** of $u$.

Formally, let $X(u) = \{ x_i \mid i \in [tl_u, tr_u] \}$ denote the ground-truth values of the array elements in the interval of $u$ under all historical updates. Then:
1. $\Sigma_u = \sum_{x \in X(u)} x \pmod M$.
2. In $\mathtt{exact\_extrema}$:
   $$m_u = \min_{x \in X(u)} x, \quad M_u = \max_{x \in X(u)} x$$

Furthermore, if $u$ is an internal node with children $L = \text{left}(u)$ and $R = \text{right}(u)$, let $X_{\text{sub}}(L)$ and $X_{\text{sub}}(R)$ denote the element values currently materialized in the subtrees of $L$ and $R$. The relation between parent aggregates and child aggregates is governed by $\tau_u$:
$$\Sigma_u \equiv a_u \cdot (\Sigma_L + \Sigma_R) + b_u \cdot |u| \pmod M$$
and for $\mathtt{exact\_extrema}$:
* If $a_u = 1$: $m_u = \min(m_L, m_R) + b_u$, $M_u = \max(M_L, M_R) + b_u$
* If $a_u = -1$: $m_u = -\max(M_L, M_R) + b_u$, $M_u = -\min(m_L, m_R) + b_u$
* If $a_u = 0$: $m_u = b_u$, $M_u = b_u$

## 3. Proof of Invariant Preservation

We prove that every operation on the segment tree preserves invariant $\mathcal{I}(u)$ for all nodes $u \in \mathcal{T}$.

### 3.1. Base Case: Initialization (`build_tree`)
During `build(A)`:
* For each leaf node $u$ spanning $[i, i]$:
  $$\Sigma_u = A[i] \pmod M, \quad m_u = M_u = A[i], \quad \tau_u = (1, 0)$$
  Since $(1, 0)$ is the identity map and $|u| = 1$, $\Sigma_u$ and extrema trivially match $A[i]$. $\mathcal{I}(u)$ holds.
* For each internal node $u$, bottom-up aggregation via `pull(u)` computes:
  $$\Sigma_u = (\Sigma_L + \Sigma_R) \pmod M, \quad m_u = \min(m_L, m_R), \quad M_u = \max(m_L, m_R), \quad \tau_u = (1, 0)$$
  Since $\tau_u = (1, 0)$, $a_u = 1, b_u = 0$. The invariant equations match exactly with child sums and extrema.

---

### 3.2. Preservation under Node Application (`apply`)

**Operation:** Given a node $u$ currently satisfying $\mathcal{I}(u)$ with state $\langle \Sigma_u, m_u, M_u, \tau_u \rangle$, a new update $\tau_{\text{new}} = (a_2, b_2)$ is applied directly to $u$.

#### 1. Modular Sum Transformation
Before application, each element $x_i \in X(u)$ contributed to $\Sigma_u = \sum_{i} x_i \pmod M$.  
Applying $f_{\tau_{\text{new}}}$ maps each element $x_i \mapsto a_2 x_i + b_2$. The new true sum is:
$$\Sigma'_u = \sum_{i \in [tl_u, tr_u]} (a_2 x_i + b_2) \equiv a_2 \left(\sum_{i \in [tl_u, tr_u]} x_i\right) + \sum_{i \in [tl_u, tr_u]} b_2 \pmod M$$
$$\Sigma'_u \equiv a_2 \Sigma_u + b_2 \cdot |u| \pmod M$$
This is precisely the update rule implemented in `apply()`:
```cpp
Residue new_sum = norm(Wide(norm(tag.a)) * tree[v].sum + Wide(norm(tag.b)) * (tr - tl + 1));
```
Thus $\Sigma'_u$ accurately incorporates the new update.

#### 2. Exact Extrema Transformation
Under $\mathtt{exact\_extrema}$, $a_2 \in \{-1, 0, 1\}$. We analyze all three cases:
* **Case $a_2 = 1$ ($x \mapsto x + b_2$):**  
  The transformation is strictly monotonically increasing. For any set $S$:
  $$\min(S + b_2) = \min(S) + b_2 = m_u + b_2$$
  $$\max(S + b_2) = \max(S) + b_2 = M_u + b_2$$
* **Case $a_2 = -1$ ($x \mapsto -x + b_2$):**  
  The map $x \mapsto -x$ is strictly monotonically decreasing. Order reverses:
  $$\min_{x \in S} (-x + b_2) = -\left(\max_{x \in S} x\right) + b_2 = -M_u + b_2$$
  $$\max_{x \in S} (-x + b_2) = -\left(\min_{x \in S} x\right) + b_2 = -m_u + b_2$$
  Hence, the minimum and maximum values swap and are negated before adding $b_2$.
* **Case $a_2 = 0$ ($x \mapsto b_2$):**  
  The mapping maps every element in the interval to constant $b_2$.  
  Since $|u| \ge 1$:
  $$m'_u = M'_u = b_2$$

In all cases, the new cached extrema $m'_u$ and $M'_u$ exactly match the true extrema of the transformed set.

#### 3. Pending Tag Composition
The prior pending tag was $\tau_u = (a_1, b_1)$. The new update $\tau_{\text{new}} = (a_2, b_2)$ acts after $\tau_u$. By Proposition 1.1:
$$\tau'_u = \tau_{\text{new}} \odot \tau_u = (a_2 a_1, a_2 b_1 + b_2)$$
When $\tau'_u$ is eventually pushed to a descendant with ground state $y$, the descendant will experience:
$$f_{\tau'_u}(y) = (f_{\tau_{\text{new}}} \circ f_{\tau_u})(y)$$
which is algebraically identical to receiving $\tau_1$ followed by $\tau_2$.  
Hence, $\mathcal{I}(u)$ is maintained after `apply(u, tag)`. $\blacksquare$

### 3.3. Preservation under Lazy Propagation (`push`)

**Operation:** Given node $u$ with children $L$ and $R$ and pending tag $\tau_u = (a_u, b_u)$. `push(u)` executes:
1. `apply(L, u.lazy)`
2. `apply(R, u.lazy)`
3. `u.lazy = (1, 0)`

#### Proof of Invariant Preservation:
1. **Children Subtrees:** By Section 3.2, applying $\tau_u$ to $L$ and $R$ preserves $\mathcal{I}(L)$ and $\mathcal{I}(R)$. The aggregates and lazy tags of $L$ and $R$ now account for $\tau_u$.
2. **Parent State:** The cached aggregates of $u$ ($\Sigma_u, m_u, M_u$) already accounted for $\tau_u$ (by $\mathcal{I}(u)$). Therefore, $\Sigma_u, m_u, M_u$ do not change during `push`.
3. **Parent-Child Structural Relation:**
   After propagation, $\tau'_u = (1, 0)$. Now:
   $$\begin{aligned}
   a'_u \cdot (\Sigma'_L + \Sigma'_R) + b'_u |u| &= 1 \cdot (\Sigma'_L + \Sigma'_R) + 0 \\
   &= \Sigma'_L + \Sigma'_R \\
   &= (a_u \Sigma_L + b_u |L|) + (a_u \Sigma_R + b_u |R|) \pmod M \\
   &= a_u (\Sigma_L + \Sigma_R) + b_u (|L| + |R|) \pmod M \\
   &= a_u (\Sigma_L + \Sigma_R) + b_u |u| \equiv \Sigma_u \pmod M
   \end{aligned}$$
   The same identity holds for extrema:
   $$\min(m'_L, m'_R) = \min(f_{\tau_u}(X(L)) \cup f_{\tau_u}(X(R))) = \min(f_{\tau_u}(X(u))) = m_u$$
   Thus, clearing $\tau_u \leftarrow (1, 0)$ is completely sound, and all three nodes ($u, L, R$) satisfy the invariant. $\blacksquare$

---

### 3.4. Preservation under Child Merge (`pull`)

**Operation:** Node $u$ has $\tau_u = (1, 0)$ (guaranteed because a partial update only recurses into children after calling `push(u)`). After children $L$ and $R$ have been updated:
$$\Sigma_u = (\Sigma_L + \Sigma_R) \pmod M$$
$$m_u = \min(m_L, m_R), \quad M_u = \max(m_L, m_R)$$

#### Proof of Invariant Preservation:
Since the interval $[tl_u, tr_u]$ is the disjoint union of $[tl_L, tr_L]$ and $[tl_R, tr_R]$:
$$X(u) = X(L) \cup X(R) \quad \text{with } X(L) \cap X(R) = \emptyset$$
1. Sum additivity:
   $$\sum_{x \in X(u)} x = \sum_{x \in X(L)} x + \sum_{x \in X(R)} x \equiv \Sigma_L + \Sigma_R \pmod M$$
2. Extrema properties:
   $$\min(X(u)) = \min(\min(X(L)), \min(X(R))) = \min(m_L, m_R)$$
   $$\max(X(u)) = \max(\max(X(L)), \max(X(R))) = \max(m_L, m_R)$$
Since $\tau_u = (1, 0)$, $a_u = 1$ and $b_u = 0$. The cached values $\Sigma_u, m_u, M_u$ match the subtree aggregates identically with no pending transformation. $\mathcal{I}(u)$ holds. $\blacksquare$

### 3.5. Induction on General Range Updates and Queries

#### Theorem 3.1 (Global Correctness of `update`)
Every call to `update([l, r], tag)` correctly updates all affected elements and restores $\mathcal{I}(v)$ for every node $v \in \mathcal{T}$.

*Proof by Structural Induction:*
Let node $v$ cover $[tl, tr]$.
* **Case 1 (Disjoint):** $[l, r] \cap [tl, tr] = \emptyset$. The algorithm returns immediately. No elements in $X(v)$ are modified. $\mathcal{I}(v)$ is unaffected.
* **Case 2 (Complete Overlap):** $[tl, tr] \subseteq [l, r]$. The algorithm calls `apply(v, tag)`. By Section 3.2, $\mathcal{I}(v)$ is preserved. Subtrees are not visited, deferring computation via $\tau_v$ with zero loss of correctness.
* **Case 3 (Partial Overlap):** $[tl, tr] \cap [l, r] \ne \emptyset$ and $[tl, tr] \not\subseteq [l, r]$.  
  1. The algorithm calls `push(v)`. By Section 3.3, $\tau_v$ is pushed to children and cleared to $(1, 0)$.
  2. Recursive calls to left and right children are disjoint or smaller subproblems; by the inductive hypothesis, they correctly update and satisfy $\mathcal{I}(\text{left})$ and $\mathcal{I}(\text{right})$.
  3. The algorithm calls `pull(v)`. By Section 3.4, parent aggregates are correctly rebuilt from updated children. $\mathcal{I}(v)$ holds.

By mathematical induction on tree height, all nodes in $\mathcal{T}$ satisfy the invariant upon termination. $\blacksquare$

#### Theorem 3.2 (Correctness of `query`)
Every call to `query([l, r])` returns the true sum modulo $M$ and exact extrema over the set $\{ x_i \mid i \in [l, r] \cap [0, n-1] \}$.

*Proof:*
Any arbitrary range $[l, r]$ is uniquely partitioned into at most $O(\log n)$ canonical maximal subtrees $[tl_k, tr_k]$.  
For each canonical node $u_k$ completely inside $[l, r]$, by Invariant $\mathcal{I}(u_k)$, the cached aggregates $\Sigma_{u_k}, m_{u_k}, M_{u_k}$ already include all prior updates (including pending $\tau_{u_k}$).  
For nodes partially overlapping $[l, r]$, `push()` is called before recursion, ensuring all pending tags above the canonical decomposition are pushed down.  
Merging the disjoint canonical aggregates via `merge_aggregates()` computes the exact sum and extrema over the union $\bigcup_k X(u_k) = [l, r]$. $\blacksquare$

## 5. Invariant Verification in Code

In `LazySegmentTree::check_invariants()` (lines 512–564), the tree structure is verified recursively without altering or pushing lazy tags. For every internal node $v$:
```cpp
Residue child_sum = norm(Wide(left.sum) + right.sum);
Residue expected_sum = norm(
    Wide(norm(node.lazy.a)) * child_sum +
    Wide(norm(node.lazy.b)) * (tr - tl + 1)
);
if (node.sum != expected_sum) {
    report.ok = false;
    report.violations.push_back("parent sum/lazy mismatch at node " + std::to_string(v));
}
```
This test asserts the algebraic invariant:
$$\Sigma_u = a_u (\Sigma_L + \Sigma_R) + b_u \cdot |u| \pmod M$$
and likewise verifies that $m_u$ and $M_u$ precisely match the transformed child extrema under $a_u \in \{-1, 0, 1\}$.

## 6. Conclusion
We have demonstrated that the lazy segment tree with affine transformation tags maintains correctness under all sequence of operations. The key design invariant—that node aggregates eagerly reflect their own pending lazy tags—enables $O(1)$ query responses at fully covered canonical nodes without needing to push lazy tags down during queries, while maintaining $O(\log n)$ worst-case time complexity per update and query.
