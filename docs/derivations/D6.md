## 1. Problem Setup and Definitions
Let `n >= 1` be the number of elements in the array, and let `b` in `{1, 2, ..., n}` be the block size used by Structure B (Square-Root Decomposition).
The array of length `n` is divided into `B = ceil(n / b)` contiguous blocks, where the first `B - 1` blocks have exact length `b` and the last block has length at most `b`.

For any half-open range `[l, r)` of width `w = r - l`:
- Let `k_l = floor(l / b)` and `k_r = floor((r - 1) / b)` be the indices of the first and last blocks touched by the operation.
- The blocks strictly between `k_l` and `k_r` are **full blocks**. There are at most `floor(w / b) <= ceil(n / b)` full blocks.
- The boundary blocks `k_l` and `k_r` (at most `2` blocks) may be **partial blocks**.

## 2. Minimising Per-Operation Work `f(b) = n / b + b`
In the worst case, a range operation spans up to `n / b` full blocks (each handled in `O(1)` time using the block's lazy tag and aggregate) and up to `2` partial blocks (each requiring a scan of `b` elements to materialize the pending tag, apply the update, and rebuild the block aggregate).

Treating `b > 0` as a continuous variable, the leading work term is proportional to:
`f(b) = (n / b) + c * b`
where `c > 0` is the ratio of partial-block work to full-block work (in the standard unweighted model, `c = 1`).

Taking the first and second derivatives with respect to `b`:
- `f'(b) = -(n / b^2) + c`
- `f''(b) = (2 * n) / b^3 > 0` for all `b > 0`

Setting `f'(b) = 0` gives the unique global minimum on `(0, infinity)`:
`-(n / b^2) + c = 0  ==>  b* = sqrt(n / c)`

For `c = 1`, `b* = sqrt(n)`, and the minimum worst-case cost is:
`f(sqrt(n)) = (n / sqrt(n)) + sqrt(n) = 2 * sqrt(n) = Theta(sqrt(n))`

Since the block size must be a positive integer, choosing `b = ceil(sqrt(n))` satisfies `sqrt(n) <= b < sqrt(n) + 1`, which keeps `(n / b) + b <= 2 * sqrt(n) + 1 = O(sqrt(n))`.

## 3. Concrete Cost Models for Structure A and Structure B
### Structure A (Lazy Segment Tree)
At each level of the segment tree of height `H = ceil(log2(n))`, a range `[l, r)` partially overlaps at most `2` nodes, and at most `2` siblings at each level can be fully covered where recursion stops.
- **Visited nodes**: `V_A(n, w) <= 4 * ceil(log2(n)) + 2`. (Special case: when `w = n`, the root covers `[0, n)` immediately, so `V_A(n, n) = 1`.)
- **Push-downs**: `P_A(n, w) <= 2 * ceil(log2(n))`, occurring only at partially overlapped internal nodes that hold a non-identity pending tag.
- **Predicted time per operation**:
  `T_A(n, w) = a_visit * V_A(n, w) + a_push * P_A(n, w)`

### Structure B (Square-Root Decomposition)
Let `b = ceil(sqrt(n))` and let `w = r - l` be the range width:
- **Full blocks touched**: `F_B(w, b) ≈ max(0, (w / b) - 1)`.
- **Partial elements touched**:
  - For an **update**, each partial boundary block materializes and rebuilds all `b` elements in that block, touching `b` elements if the range stays inside one partial block (`w < b` and does not cross a boundary) or `2 * b` elements if it crosses a boundary.
  - For a **query**, only the overlapped elements in the partial blocks are scanned, which averages `min(w, b)` elements.
- **Predicted time per operation**:
  `T_B(n, w) = b_full * F_B(w, b) + b_elem * E_B(w, b)`

## 4. Dependence on Width, Alignment, and Crossover
1. **Alignment effect in Structure B**: If `l` and `r` are multiples of `b` (`l % b == 0` and `r % b == 0`), there are `0` partial blocks (`E_B = 0`) and the operation performs purely `w / b` full-block `O(1)` updates or merges. Unaligned endpoints incur up to `2 * b` partial-element updates.
2. **Width sweep and crossover**:
   - Because `b_elem` is a tight sequential loop over contiguous `int64_t` values (auto-vectorized by the compiler and L1-cache friendly) whereas `a_visit` and `a_push` involve conditional branches and non-contiguous array jumps (`2 * v` and `2 * v + 1`), Structure B has a much smaller per-unit constant than Structure A.
   - Consequently, for small `w` (`w <= b`), `T_B(n, w) < T_A(n, w)`.
   - As `w` increases toward `n`, `F_B(w, b) ≈ w / b` grows linearly in `w` up to `sqrt(n)`, while `V_A(n, w)` remains bounded by `4 * log2(n)` (and drops to `1` at `w = n`). Thus a crossover occurs at the width `w_cross` where:
     `b_full * (w_cross / b) + b_elem * E_B ≈ a_visit * V_A + a_push * P_A`
