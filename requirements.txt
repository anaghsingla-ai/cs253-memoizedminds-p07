# CS253 Lazy Propagation - build requirements
#

# There are no third-party C++ libraries to download; the project uses only
# the C++ standard library.
#
# Required system tools:
#   - C++17 compiler (GCC/g++ or Clang; MSVC is also supported by CMake)
#   - CMake 3.16 or newer
#   - A compatible build tool:
#       Windows: MinGW Make (mingw32-make) or Visual Studio build tools
#       Linux/macOS: make or Ninja
#
# Do not run "pip install -r requirements.txt" for this file.
# Install the system tools with your OS package manager if they are missing.
